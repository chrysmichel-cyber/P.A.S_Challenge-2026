# P.A.S_Challenge-2026
**N’Zassa** est un jeu d’aventure éducatif qui invite les joueurs à explorer les régions d’Afrique, découvrir leurs langues, leurs traditions et leurs histoires. À travers des villages interactifs, des personnages attachants, des contes et des quiz, les joueurs apprennent tout en s’amusant.
